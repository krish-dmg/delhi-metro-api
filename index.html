🚇 Delhi Metro API

Serverless shortest path API · Powered by Dijkstra's Algorithm

📡 Endpoints

GET /route?from=StationA&to=StationB
Returns shortest path, interchange stations, metro lines, and travel time.
GET /route/stations
Returns a full list of all available station names.
